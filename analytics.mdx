## Key Metrics

Track the most important performance indicators to measure campaign success and ROI.

<ExpandableGroup>
  <Expandable title="Engagement Metrics" default-open="true">
    Open rates, click-through rates, and time spent engaging with your content provide insights into audience interest.
  </Expandable>
  <Expandable title="Conversion Metrics" default-open="false">
    Track how campaigns drive desired actions like purchases, sign-ups, or downloads.
  </Expandable>
  <Expandable title="Attribution Metrics" default-open="false">
    Understand the customer journey and how different touchpoints contribute to conversions.
  </Expandable>
</ExpandableGroup>

| Metric | Formula | Benchmark |
|--------|---------|-----------|
| Open Rate | (Opens / Sent) × 100 | `20-30%` |
| Click Rate | (Clicks / Opens) × 100 | `3-5%` |
| Conversion Rate | (Conversions / Clicks) × 100 | `2-4%` |
| ROI | (Revenue - Cost) / Cost × 100 | `>200%` |

<Callout kind="info">
  Benchmarks vary by industry and audience. Use historical data from your own campaigns to establish relevant targets.
</Callout>

## Predictive Analytics

Our AI analyzes historical data to predict future performance and provide optimization recommendations.

<CodeGroup tabs="JavaScript,Python">
  ```javascript
const predictions = await api.getPredictions({
  campaignId: 'camp_123',
  metrics: ['open_rate', 'click_rate', 'conversions'],
  timeframe: 'next_30_days'
});

predictions.forEach(pred => {
  console.log(`${pred.metric}: ${pred.predicted_value} (${pred.confidence}%)`);
});
```
  ```python
predictions = api.get_predictions({
    'campaign_id': 'camp_123',
    'metrics': ['open_rate', 'click_rate', 'conversions'],
    'timeframe': 'next_30_days'
})

for pred in predictions:
    print(f"{pred['metric']}: {pred['predicted_value']} ({pred['confidence']}%)" )
```
</CodeGroup>

## Data Export

Export analytics data for further analysis in external tools or for integration with business intelligence systems.

<CodeGroup tabs="cURL,JavaScript">
  ```bash
curl -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"format":"csv","metrics":["open_rate","click_rate"],"dateRange":{"start":"2024-01-01","end":"2024-12-31"}}' \
  https://api.miaimarketing.com/v1/analytics/export
```
  ```javascript
const exportData = {
  format: 'csv',
  metrics: ['open_rate', 'click_rate'],
  dateRange: {
    start: '2024-01-01',
    end: '2024-12-31'
  }
};

const response = await fetch('https://api.miaimarketing.com/v1/analytics/export', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify(exportData)
});
```
</CodeGroup>
