## Campaign Builder

Our visual campaign builder makes it easy to create sophisticated marketing workflows without technical expertise.

<CodeGroup tabs="API,SDK">
  ```javascript
const campaign = {
  name: 'Q4 Product Launch',
  type: 'email',
  segments: ['new_subscribers', 'past_customers'],
  schedule: {
    startDate: '2024-10-01',
    frequency: 'weekly',
    endDate: '2024-12-31'
  },
  content: {
    subject: 'Introducing Our Latest Innovation',
    template: 'product_launch_v2'
  }
};

await api.createCampaign(campaign);
```
  ```python
campaign_data = {
    'name': 'Q4 Product Launch',
    'type': 'email',
    'segments': ['new_subscribers', 'past_customers'],
    'schedule': {
        'start_date': '2024-10-01',
        'frequency': 'weekly',
        'end_date': '2024-12-31'
    },
    'content': {
        'subject': 'Introducing Our Latest Innovation',
        'template': 'product_launch_v2'
    }
}

api.create_campaign(campaign_data)
```
</CodeGroup>

## Performance Tracking

Monitor campaign effectiveness with comprehensive analytics and real-time reporting.

| Metric | Description | Target Range |
|--------|-------------|--------------|
| Open Rate | Percentage of recipients who open emails | `15-25%` |
| Click Rate | Percentage who click on links | `2-5%` |
| Conversion Rate | Percentage who complete desired actions | `1-3%` |
| Bounce Rate | Percentage of undeliverable emails | `<2%` |

## Advanced Features

Take your campaigns to the next level with powerful automation and personalization features.

<Expandable title="Workflow Automation" default-open="false">
  Create complex automated sequences that trigger based on user behavior, such as welcome series for new subscribers or re-engagement campaigns for inactive users.
</Expandable>

<Expandable title="Personalization" default-open="false">
  Use dynamic content insertion to personalize messages with recipient data like name, location, and purchase history for higher engagement rates.
</Expandable>

<CodeGroup tabs="JavaScript,Python">
  ```javascript
const personalizedCampaign = {
  name: 'Personalized Recommendations',
  type: 'email',
  personalization: {
    variables: ['firstName', 'lastPurchase', 'location'],
    rules: [
      { condition: 'location == "New York"', template: 'nyc_special' },
      { condition: 'lastPurchase > 100', template: 'vip_offer' }
    ]
  }
};

await api.createCampaign(personalizedCampaign);
```
  ```python
personalized_campaign = {
    'name': 'Personalized Recommendations',
    'type': 'email',
    'personalization': {
        'variables': ['firstName', 'lastPurchase', 'location'],
        'rules': [
            {'condition': 'location == "New York"', 'template': 'nyc_special'},
            {'condition': 'lastPurchase > 100', 'template': 'vip_offer'}
        ]
    }
}

api.create_campaign(personalized_campaign)
```
</CodeGroup>
